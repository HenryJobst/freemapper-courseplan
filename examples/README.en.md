# Example events

[Deutsch](README.md)

This folder will hold finished events built on maps from
[freemapper's examples](https://github.com/HenryJobst/freemapper/tree/main/examples): the project file, the IOF
XML 3.0 export for OE, the Purple Pen export (`.ppen`), the check findings and, once freemapper-print prints
courses, the print PDF with a preview image. The first example will be a sprint training on the map of Lübeck's
old town. It arrives with the first version that can set, check and export courses.
