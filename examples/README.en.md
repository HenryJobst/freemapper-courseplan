# Example events

[Deutsch](README.md)

Finished events on the maps "Gleisdreieck" and "Rummelsburger Bucht" by Remo Madella (MOO Challenge Berlin 2025). He
released both on 2026-11-12 for use within the freemapper suite; that is not an open licence (see `ATTRIBUTION.txt` in
each folder). Each example comes with its project file, the commands that made it and the output of `check`. The export
to IOF XML 3.0 is included as `course-data.xml`; it is checked against the IOF schema, and an import into OE has not been
tried. The Purple Pen export of the Rummelsburger Bucht example is included as `rummelsburg-sprint.ppen`; that file has
not been opened in Purple Pen yet. The pictures are captures of the editor; a printed PDF from freemapper-print will
follow.
