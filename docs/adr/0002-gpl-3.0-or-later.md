# 0002. GPL-3.0-or-later

Date: 2026-11-08
Status: Proposed

## Context

freemapper and freemapper-print are GPL-3.0-or-later. freemapper-courseplan takes over their code. Purple
Pen's `.ppen` format and control description symbols are BSD-style and can be combined with the GPL.

## Decision

freemapper-courseplan is licensed GPL-3.0-or-later.

## Consequences

- Code from the siblings and from OOM can be used directly.
- Anyone who distributes the program or code built on its library must do so under the GPL.
- Cost if wrong: relicensing needs every contributor's consent and replacements for the code taken over.

Source: design §3; freemapper-print ADR 0002.
