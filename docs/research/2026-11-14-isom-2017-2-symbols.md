# ISOM 2017-2 symbol numbers used by the forest rules

Date: 2026-11-14. Task 1 of the forest maps plan (ADR 0092).

## Sources

- **S1, the specification.** IOF, *International Specification for Orienteering Maps ISOM 2017-2*, copy of the
  "Adjusted version published January 2019" with errata up to 23.01.2022, as hosted by FISO:
  <https://www.fiso.it/_files/f_media/2022/01/25011.pdf>. The IOF publishes the document (CC BY-ND 4.0) on its mapping
  page <https://orienteering.sport/iof/mapping/> and on <https://omapwiki.orienteering.sport/specifications/isom/>
  (that page answered 403 to the fetch tool). The text is read, not copied: this file quotes only the symbol
  names. Revision 6 (January 2024) was not available as a file; the rows below must be compared with it when it is
  fetched (the errata of 2022 renamed 513 to 513.1, and Revision 6 may do more).
- **S2, Mapper's symbol set.** `symbol sets/10000/ISOM 2017-2_10000.omap` and `symbol sets/src/ISOM 2017-2_15000.xmap` in
  <https://github.com/OpenOrienteering/mapper> (master, last change of the file `eae21b0`, 2025-05-18; latest release
  tag v0.9.6; repository licence GPL-3.0). The symbol set id inside the file is `ISOM 2017-2`
  (`<symbols id="ISOM 2017-2">`), 191 symbols. freemapper embeds the same set and writes the same id
  (`crates/freemapper/src/omap/symbol_set.rs`, test `assert_eq!(set.name, "ISOM 2017-2")`).

Both sources agree on every row marked *confirmed*. "Confirmed" means the number and name appear in S1 and S2.

## Numbers of the ISOM 2017-2 rule data that differ in ISOM 2000

`forest-sample.omap` (symbol set id `ISOM2000`) uses the 2000 numbering. The rule data uses the 2017-2 numbers; on that
sample map they point at other objects.

| Number | ISOM 2017-2 | ISOM 2000 (`forest-sample.omap`) |
|---|---|---|
| 109 | Small knoll | Erosion gully |
| 110 | Small elongated knoll | Small erosion gully |
| 112 | Pit | Small knoll |
| 304 | Crossable watercourse | not present |
| 305 | Small crossable watercourse | Crossable watercourse |
| 306 | Minor/seasonal water channel | Crossable small watercourse |
| 309 | Narrow marsh | Uncrossable marsh |
| 505 | Footpath | Vehicle track |
| 506 | Small footpath | Footpath |
| 507 | Less distinct small footpath | Small path |
| 508 | Narrow ride | Less distinct small path |
| 516 | Fence | Power line |
| 517 | Ruined fence | Major power line |
| 520 | Area that shall not be entered | Ruined stone wall |
| 528 | Prominent line feature | Permanently out of bounds |
| 708 | Out-of-bounds boundary | Crossing point |
| 710 | Crossing point | Dangerous area |

Numbers with the same meaning in both: 601, 602, 701, 706, 709, 712, 713. A forest rule run on an ISOM 2000 map would
therefore give wrong findings, which is why ISOM 2000 is refused (ADR 0092).

## Unconfirmed

- **714** is a symbol of ISSprOM 2019-2 (temporary construction or closed area). ISOM 2017-2 has no 714 in S1 or S2. No
  forest rule uses it; the forest rule data already leaves it out.
- **Revision 6 of ISOM 2017-2 (January 2024)** was not read. If it moved one of the numbers above, the forest rules
  follow S2, which Mapper still ships. No number in the table is known to differ.
- Column D proposals for forest descriptions: this repository holds no table of them (the editor offers IOF symbol ids
  from the description library, not ISOM numbers), so nothing is to confirm.

No number needed by a forest rule is unconfirmed, so no rule drops out of the forest rules for lack of a number.

## Symbol set names

Mapper and freemapper write `ISOM 2017-2`. Mapper also ships `ISOM2017` (first edition) and `ISOM2000`, and a file
that came from an older conversion can carry either. Task 3 accepts only the normalised name `isom2017-2` (letters
lowercased, spaces removed).
